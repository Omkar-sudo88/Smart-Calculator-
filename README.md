# Smart Calculator Pro

An all-in-one calculator web application built using HTML, CSS and JavaScript.

## Features

- Scientific Calculator
- Percentage Calculator
- Percentage Change Calculator
- Discount and GST Calculator
- 10th Marks Calculator
- CGPA / SGPA Calculator
- EMI Calculator
- Calculation History
- Dark / Light Mode
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
